Kolejka priorytetowa: 
Kopiec Fibonacciego
 - jest to las drzew dwumianowych nie uporządkowanych według wysokości
 - Każdy węzeł ma klucz, wskaźniki: next, prev, child, i atrybut mark
 - dla każdego węzła może być usunięte najwyżej jedno poddrzewo, jeśli dany węzeł ma usunięte poddrzewo to jest zamarkowany
 - Złożoność operacji: Insert: O(1), Max: O(1), DeleteMax: O(log n) przez Consolidate

 Słownik:
 Drzewo AVL
 - zrównoważone drzewo BST
 - dla dowolnego węzła różnica wysokości poddrzew jest nie większa niż 1
 - każdy węzeł ma klucz, wskaźnik: left, right, i atrybut bl (balance)
 - atrybut balance bl = hL - hR (wysokość lewego - wysokość prawego)
 - Złożoność operacji: Search, Insert, Delete: O(log n)

struct node
{
    node *left, *right;
    int val;
}
node* Search(int val)
{
    if(!root)
        return NULL;
    node* n = root;
    while(n && n->val != val)
    {
        if(val > n->val)
            n = n->right
        else
            n = n->left
    }
    return n;
}
